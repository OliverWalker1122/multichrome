Isolated Browser Profiles Without the Cloud

Run multiple isolated Google Chrome and C++ privacy browser environments side by side with fail-closed sing-box proxy tunnels, native CDP cookie & grid tooling, and password-encrypted offline backups.

Download Latest Release View Source on GitHub

Dual Browser Engines

Choose official Google Chrome or the on-demand C++ fingerprint-chromium privacy kernel per profile — zero JS prototype hooks or forced extensions.

Fail-Closed Proxy Isolation

Managed sing-box routing blocks direct fallback, QUIC bypass, and DNS or WebRTC leaks across HTTP, SOCKS5, VLESS, VMess, Trojan, SS, Hysteria2, and TUIC.

E2EE Offline Backups

Export and restore portable settings, re-encrypted proxy configs, and profile fingerprint seeds locally via scrypt + AES-256-GCM (.mcbackup).

Batch & Window Tiling

Bulk-create numbered profiles with sequential proxy assignment, act on multi-selected profiles, and tile running windows cleanly across the display.

Native CDP Cookie Transfer

Import and export standard JSON or Netscape HTTP cookies directly over private CDP without installing extra extensions.

Guarded CDP & 4-Tool MCP

Opt-in loopback 127.0.0.1 CDP guard (default port 18922) with DNS-rebinding defense and Streamable HTTP / stdio MCP for external agents.

Verify Before You Run

Every GitHub Release publishes SHA-256 checksums and SLSA build provenance attestations for Windows, macOS, and Linux installers. 

sha256sum -c SHA256SUMS.txt
gh attestation verify <downloaded-installer> --repo OliverWalker1122/multichrome
